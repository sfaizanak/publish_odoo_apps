POS Cashier Risk Monitor

Explainable monitoring for unusual POS discounts, price overrides, deletions, refunds and cashier behaviour.

The module identifies transactions for review. It does not determine fraud and does not interrupt the POS payment flow.

Included capabilities

  • Configurable, safe rule catalogue with explainable risk cases.
  • Cashier and POS behavioural baselines with fallback selection.
  • Optional Isolation Forest anomaly scoring with graceful fallback.
  • Manager workflow, activities, critical notifications and reports.
  • Demo evaluation scenarios and precision/false-alert metrics.

Requirements

Odoo 19.0, Point of Sale and Discuss/Mail. Scikit-learn is optional; rule and baseline monitoring continue when it is unavailable.
